# Scene images

Drop one image per scene here. The file name (without extension) must match the scene's `bg.img`
in `js/scenes.js`: `02.jpg`, `03.jpg` … `24.jpg`, plus optional `wood.jpg` (table background),
`burst.jpg`, `candy.png` and `toffee.png` (transparent product shots).

`.jpg`, `.png`, `.webp` and `.jpeg` are all picked up. Vertical 9:16 images (e.g. 1080x1920) fit best;
anything else is cropped to fill the frame. Scenes without an image use a built-in drawn background.
