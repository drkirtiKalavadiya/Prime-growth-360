# Reference reel: full breakdown

Source: 720×1280, 29.97 fps, 35.6 s, AAC stereo 44.1 kHz. Style name used here: **Orange Kinetic**.
Everything below is already coded in this template. Times are from frame analysis (scene-diff + caption-change detection + spectrogram).

## 1. Style DNA (global)

| Element | Value |
|---|---|
| Font | **Poppins**: ExtraBold 800 for captions, Black 900 for headlines (tight tracking −0.045em, line-height 0.86) |
| Accent colour | **#FF6600** orange (sampled RGB 253,100,0) |
| Second colour | **#FFFFFF** white. No third colour. The house icon uses an orange→**#FF9A3C** gradient |
| Captions | 1 word at a time, lowercase as spoken, white, ~60 px @1080w, soft dark shadow, centred at **56% height** (chest), 4-frame spring pop |
| Headlines | 2–4 stacked words, mixed sizes (small connector word + giant key word), orange for the key word, rest white. Captions are hidden while a headline is on screen |
| Depth | Key headline words sit **behind the speaker's head** (person cut-out). Connector/emphasis words like "sell!" sit in front |
| Text IN | Stretched 2.4× tall + heavy **vertical motion blur** → snaps to size in 8 frames (looks like vertical bars/slats). Lines stagger 3 frames |
| Text OUT | Drifts up ~90 px + vertical blur + fade in 8 frames |
| Camera | Digital **punch zooms** 1.00↔1.12–1.15 in 5 frames (ease-out), held until the next punch |
| Grade | Saturation +18%, contrast +6%, slight lift. Teal screens and orange wood pop |
| Music | Quiet ambient pad bed, with a constant high tone (~1.17 kHz) under the whole voice. No beat drops |
| SFX | Sub **boom** on every zoom punch and headline, **whoosh** on text in/out, **shimmer/ding** when a headline lands, **whip** + **downlifter** on the angle change, **slash** on the strike bar, **pop** on small text |

## 3. Shot list (what the camera did)

1. 0.0–8.3: Angle A, wide frontal across the desk (the person is small in frame, with headroom for text)
2. 8.3–12.6: Angle B, closer, from the side. Entered with a whip pan
3. 12.6–35.6: Angle A2, frontal medium. Hard cut. Variety comes only from punch zooms (16.45, 21.35, 33.4)

For your new video: film two angles if you can (wide + side/close). If you only have one angle, the whip still works as a transition and the punch zooms give the variety.
